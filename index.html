INFORME EVA 2

Plan Maestro y Ejecución de Pruebas QA

Sistema LocalCode / mi-leet-code-cs50

1. Introducción

Este informe presenta el desarrollo de pruebas aplicado al sistema LocalCode, correspondiente al repositorio mi-leet-code-cs50. Para esta evaluación se utiliza el problema Mario en lenguaje C, ya que permite revisar funcionalidades importantes como Run Code, Submit, manejo de errores, integración entre frontend y backend, usabilidad, rendimiento básico y seguridad de endpoints.

El trabajo se organiza mediante un Plan Maestro de Pruebas, requerimientos, historia de usuario, casos de prueba, criterios BDD, matriz RTM, evidencias, hallazgos y recomendaciones. La finalidad es aplicar de forma práctica los contenidos vistos en clases y documentar los resultados obtenidos durante la revisión del sistema.

2. Plan Maestro de Pruebas

2.1 Objetivo del plan

El objetivo del Plan Maestro de Pruebas es organizar la estrategia de testing aplicada a LocalCode, definiendo el alcance, los tipos de prueba, los criterios de entrada y salida, los casos de prueba, los riesgos, las evidencias y las recomendaciones.

2.2 Alcance de las pruebas

Dentro del alcance

  • Problema Mario en lenguaje C.
  • Editor de código de LocalCode.
  • Botones Run Code y Submit.
  • Manejo de errores de compilación.
  • Comunicación frontend-backend.
  • Usabilidad, accesibilidad básica, rendimiento y endpoints.

Fuera del alcance

  • Probar todos los problemas disponibles.
  • Modificar el código fuente interno.
  • Pruebas de carga con muchos usuarios.
  • Pentesting avanzado.
  • Automatización con herramientas externas.
  • Despliegue en producción.

2.3 Responsable

Las pruebas fueron realizadas de forma individual por la estudiante, encargada de ejecutar los casos de prueba, registrar evidencias y documentar los resultados obtenidos.

7.1 Hallazgo principal

El principal hallazgo identificado corresponde a la usabilidad del editor de código. El espacio del editor es reducido, lo que dificulta visualizar el código completo, revisar errores pequeños y modificar líneas de forma rápida. Además, al ejecutar Run Code, el sistema muestra el resultado general, pero no presenta la salida completa generada por el programa.

7.2 Recomendaciones

  • Ampliar el área visible del editor de código.
  • Agregar una opción de pantalla completa para escribir código.
  • Mostrar la salida generada junto al resultado Accepted o Failed.
  • Mantener mensajes de error claros y controlados.
  • Repetir las pruebas funcionales antes de cambios importantes.
  • Revisar periódicamente los endpoints para evitar exposición de información sensible.
  • Medir tiempos de respuesta si se agregan más problemas o usuarios al sistema.

8. Conclusión

Se concluye que el sistema LocalCode funcionó correctamente dentro del alcance definido para esta evaluación. Las pruebas realizadas permitieron validar funcionalidades importantes como Run Code, Submit, manejo de errores, integración frontend-backend, rendimiento básico y seguridad/endpoints. Los resultados principales fueron positivos, ya que el sistema respondió correctamente y no presentó fallas críticas.

Como hallazgo, se identificó una oportunidad de mejora en la usabilidad del editor de código, debido a su tamaño reducido y a la falta de visualización de la salida completa generada por el programa. Por ello, se recomienda mejorar el editor y entregar mayor retroalimentación visual al usuario.

Anexo 1. Código de prueba utilizado

El siguiente código corresponde a la solución en lenguaje C ingresada en el editor de LocalCode para ejecutar las pruebas funcionales del problema Mario. No corresponde al código fuente interno del sistema, sino al dato de prueba utilizado para validar Run Code y Submit.

#include <stdio.h>

int main(void)
{
    int altura;
    scanf("%d", &altura);

    for (int fila = 1; fila <= altura; fila++)
    {
        for (int espacio = 0; espacio < altura - fila; espacio++)
        {
            printf(" ");
        }

        for (int bloque = 0; bloque < fila; bloque++)
        {
            printf("#");
        }

        printf("\n");
    }

    return 0;
}
